# Mikan 2.0

**Mikan 2.0 — независимый форк [Mikan](https://github.com/Miroshka000/mikan), VPN-панели на ядре mihomo.**

Цель проекта — сохранить полезную основу панели и развивать открытые дополнительные возможности для операторов и разработчиков.

> **Статус разработки:** экспериментальный форк. Не используйте эту ветку как production-установщик, пока не проверены сборка, миграция, подпись релизов и обновление.

## Приоритеты проекта

- **Ноды Pterodactyl:** исследовать Egg для обычного игрового хостинга без root-доступа и Docker socket внутри серверного контейнера.
- **Полноценный магазин аддонов:** несколько Telegram-ботов, платёжные интеграции и сторонние расширения с разграничением прав.
- **API для разработчиков:** ключи с ограниченными разрешениями, подписанные webhooks, стабильные версии API и примеры собственных ботов.
- **Бесплатные возможности основной версии:** перенос панели, внешние источники подписок и отдельный Telegram-бот администратора.

Подробная дорожная карта и технические ограничения описаны в [дорожной карте Mikan 2.0](docs/mikan20-roadmap.md).

## Текущий статус

Дорожная карта описывает планы, а не уже реализованные функции. В частности, режим Pterodactyl требует публикации и проверки standalone-бинарников ноды, а затем проверки выделенных портов на реальном Pterodactyl/Wings.
