Mikan 2.0 — открытый форк Mikan. Базовые функции из этой дорожной карты планируется выпускать бесплатно: сумма пожертвований не является условием начала разработки.

В первую очередь работаем над нодами на Pterodactyl, переносом панели между серверами, безопасными внешними подписками, отдельным административным Telegram-ботом, магазином аддонов и API для собственных ботов.

Все пункты ниже — **план разработки, а не уже готовые функции**. Совместимость нод с конкретным игровым хостингом будет зависеть от доступных портов и сетевых ограничений провайдера.
