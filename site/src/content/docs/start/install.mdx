## Статус установщика

Установщик Mikan 2.0 адаптирован к отдельным подписанным релизам форка. **Первый релиз ещё не опубликован**, поэтому команда ниже пока не должна использоваться на production-сервере. Перед первым релизом необходимо настроить секрет подписи релизов GitHub Actions и проверить сборку.

После публикации первого стабильного релиза на чистом сервере Ubuntu 22.04+ или Debian 12+ (amd64/arm64) будет доступна установка одной командой:

```bash
curl -fsSL https://github.com/m0ruy0/mikan-2.0/releases/latest/download/install.sh | sudo bash
```

Установщик проверяет подпись манифеста релиза и контрольную сумму бинарника, затем запускает мастер настройки панели. Не скачивайте установщик из случайных зеркал и не используйте релизы оригинального Mikan для Mikan 2.0.

## Установка удалённой ноды

После появления релиза, в панели откройте **Ноды → Добавить ноду** и скопируйте выданную команду с ключом подключения. Она будет иметь вид:

```bash
curl -fsSL https://github.com/m0ruy0/mikan-2.0/releases/latest/download/install.sh | sudo bash -s -- --join КЛЮЧ
```

Ключ даёт ноде доступ к панели — не публикуйте его и не добавляйте в скриншоты или логи.

## Pterodactyl

Поддержка Pterodactyl пока находится в дорожной карте, а не в выпущенном установщике. Для неё потребуется отдельный Egg, standalone-бинарник ноды и проверка реальных TCP/UDP allocations провайдера. Не запускайте VPS-установщик внутри игрового контейнера.
