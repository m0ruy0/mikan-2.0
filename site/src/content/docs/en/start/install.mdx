## Installer status

The Mikan 2.0 installer is being adapted for its own signed releases. **The first release has not been published yet**, so do not use the command below on a production server. Before the first release, the repository's release-signing secret must be configured and the build verified.

After the first stable release is published, a clean Ubuntu 22.04+ or Debian 12+ server (amd64/arm64) will support one-command installation:

```bash
curl -fsSL https://github.com/m0ruy0/mikan-2.0/releases/latest/download/install.sh | sudo bash
```

The installer verifies the release manifest signature and the downloaded binary checksum, then starts the setup wizard. Do not use random mirrors or original Mikan releases to install Mikan 2.0.

## Install a remote node

After a release is available, open **Nodes → Add node** in the panel and copy the generated join command. It will look like this:

```bash
curl -fsSL https://github.com/m0ruy0/mikan-2.0/releases/latest/download/install.sh | sudo bash -s -- --join KEY
```

The join key grants a node access to the panel. Do not publish it or include it in screenshots or logs.

## Pterodactyl

Pterodactyl support is still on the roadmap, not part of a released installer. It requires a dedicated Egg, a standalone node binary and testing against the provider's actual TCP/UDP allocations. Do not run the VPS installer inside a game-server container.
