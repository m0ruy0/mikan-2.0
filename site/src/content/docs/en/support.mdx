Mikan 2.0 is an open-source fork of Mikan. The core features in this roadmap are planned for the free release; donations are not a prerequisite for starting development.

Our first priorities are Pterodactyl nodes, moving the panel between servers, safely importing external subscriptions, a separate Telegram admin bot, an addon marketplace and an API for custom bots.

Everything below is a **development plan, not a claim that these features are already implemented**. Support for a particular game host depends on its port allocations and network restrictions.
